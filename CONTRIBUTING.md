# Contributing

## Contribution workflow

1. Create a branch.
2. Explain the learning objective.
3. Keep the change limited to one act or assignment.
4. Add or update tests, evals, or evidence.
5. Preserve model answers separately from participant instructions.
6. Document security, contract, and rollback impact.
7. Open a pull request with the required reviewers.

## Pull-request expectations

Include:

- summary;
- act and assignment affected;
- participant impact;
- tests or evals;
- security and privacy impact;
- backward-compatibility impact;
- rollback plan;
- residual risks.

Do not weaken tests or expected outcomes merely to make a contribution pass.
