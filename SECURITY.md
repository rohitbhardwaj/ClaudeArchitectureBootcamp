# Security Policy

This repository is for workshop and educational use. Do not use production secrets, credentials, customer data, or privileged service identities.

## Report a security issue

Do not publish sensitive vulnerabilities in a public issue. Contact the repository owner or workshop organizer through the private channel provided for the event.

## Workshop safety rules

- Use synthetic data.
- Keep credentials outside prompts and source files.
- Treat user and retrieved content as untrusted.
- Use least-privilege tool access.
- Require approval and idempotency for writes.
- Do not run destructive commands.
- Do not connect workshop code directly to production systems.
